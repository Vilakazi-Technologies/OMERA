# Security policy

## Report a vulnerability

Use GitHub private vulnerability reporting on this repository. Do not open a
public issue. Include the route, the impact, and reproduction steps. Do not
include real user data or live keys.

A dedicated security email is an owner input. Add it here before public launch.

## Scope

- The production deployment of Omera.
- The `xavani_omera` service.
- The repository code on the default branch.

## Out of scope

- Findings that need a compromised device or a leaked Clerk session.
- Volumetric attacks against Vercel or Render infrastructure.
- Reports from automated scanners without a working proof.
